## 0.1.0 — 첫 비공개 테스트

2026-09-08 심사 요청 접수. 아래는 제출한 테스트 버전의 기능 안내이며, Google Play 테스트 배포와 실제 설치 가능 여부는 아직 확인 전입니다.

- KTF·LGT 게임 파일을 여러 개 가져오거나 지정한 폴더에서 새 파일을 찾습니다.
- 클래식·플랫 키패드와 가로·세로 배치를 제공합니다. 화면 키패드를 숨겨 게임패드와 함께 사용할 수 있습니다.
- 게임 속 문자 입력에 천지인 한글·영문 반복 누르기를 지원합니다.
- 레트로·Xbox·PlayStation 게임패드 배열을 선택하고 공통·게임별 키를 매핑합니다. 매핑 창에서 누른 버튼을 표시하며 RG Rotate의 L2·R2 디지털 입력을 연결했습니다.
- 화면 비율을 유지한 확대, 0.5–4배속, 라이트·다크·시스템 테마, 상태바와 진동을 설정합니다.
- 게임별 저장 내보내기·가져오기를 제공합니다. 앱 삭제나 데이터 지우기 전에 필요한 저장을 앱 바깥에 보관할 수 있습니다.
- 앱 정보에서 개인정보처리방침을 오프라인으로 읽을 수 있습니다.

1차 목록은 기존 28개에 리듬스타 KTF·2010프로야구 LGT·템페스트 LGT를 더한 **31개**입니다. 파일 선정과 배포는 최종 호환 판정과 구분하며, 기기·게임별 실행과 저장 범위는 추가로 확인합니다.

## English

Version 0.1.0 was submitted for its first closed-test review on September 8, 2026. Test distribution and installation availability have not yet been verified.

This test version includes KTF/LGT file import and folder scanning; classic and flat keypads; portrait and landscape layouts; Korean Cheonjiin and multi-tap English input; configurable retro, Xbox, and PlayStation controller layouts; live mapping feedback and RG Rotate L2/R2 input; playback speed, themes, status-bar and vibration settings; per-game save export/import; and an offline privacy policy in app information.

The first test roster contains 31 entries. Roster inclusion or file availability does not establish final compatibility with every game or device.
