# WIPI-X

**그 시절 피처폰 게임을, 오늘의 Android에서.**

WIPI-X는 피처폰 WIPI 게임을 Android에서 즐길 수 있도록 개발 중인 에뮬레이터입니다. Valio Studio가 만들고 있습니다.

[공식 홈페이지](https://wipix.valiostudio.com/) · [앱 출시 안내](https://wipix.valiostudio.com/ko/download/) · [게임 카탈로그](https://wipix.valiostudio.com/ko/games/) · [문제 제보](https://github.com/hun99999/wipi-x-releases/issues/new/choose)

## 앱 받기

**WIPI-X 앱의 공식 설치와 업데이트는 Google Play에서만 제공합니다.** 현재 첫 출시를 준비하고 있으며, 스토어 공개 후 홈페이지의 앱 출시 안내에 공식 링크를 추가합니다.

이 GitHub는 프로젝트 소개, 사용 안내, 호환 현황과 사용자 지원을 위한 공간입니다. 앱 소스코드, APK/AAB 설치 파일 및 게임 파일은 게시하지 않습니다.

## WIPI-X로 할 수 있는 일

- 보유한 게임 파일을 선택하거나 게임 전용 폴더를 지정해 라이브러리에 추가합니다.
- 익숙한 피처폰 키패드로 조작하고, 화면과 입력 설정을 조절합니다.
- 게임을 이름순·최근 실행순으로 찾아보고 즐겨찾기로 모읍니다.
- 게임 내 저장을 마친 뒤 게임별 저장 파일을 내보내고, 같은 게임에 수동으로 복원합니다.

현재 개발·테스트 중인 기능을 소개한 것으로, 기기와 게임에 따라 동작이 다를 수 있습니다. 공개 버전의 변경 내용은 출시 후 안내합니다.

## 처음 시작하기

1. Google Play 공개 후 공식 앱을 설치합니다.
2. 사용할 게임 파일을 Android의 게임 전용 폴더에 준비합니다.
3. WIPI-X에서 **폴더 지정** 또는 파일 가져오기로 추가하고 게임을 선택합니다.

[자세한 시작 안내](docs/GETTING_STARTED.md) · [호환성 및 1차 테스트 대상](docs/COMPATIBILITY.md) · [문의 안내](SUPPORT.md)

## 호환성

1차 테스트 대상은 **28개(KTF 17개 · LGT 11개)**입니다. 현재 모두 최종 검증 중이며, 대상 선정이 모든 기기에서의 정상 동작이나 전체 게임 진행을 보증하지는 않습니다. 호환 결과는 통신사, 정확한 게임 파일, WIPI-X 버전을 기준으로 안내합니다.

홈페이지의 전체 게임 카탈로그는 게임을 찾아보기 위한 자료입니다. 카탈로그에 있는 모든 게임이 1차 지원 대상인 것은 아닙니다.

## 제보와 제안

실행 문제, 사용 중 불편한 점, 개선 아이디어는 [GitHub Issues](https://github.com/hun99999/wipi-x-releases/issues/new/choose)에 남겨 주세요. 기기 모델, Android 버전, 앱 버전, 게임·통신사와 재현 방법이 있으면 확인에 도움이 됩니다.

이슈는 공개됩니다. 개인정보, 게임 원본, 저장 파일이나 비공개 다운로드 링크는 첨부하지 마세요.

## English

WIPI-X is an Android emulator in development for classic WIPI feature-phone games, made by Valio Studio.

The app will be distributed **exclusively through Google Play**. The first release is in preparation; the official store link will be announced on the [website](https://wipix.valiostudio.com/en/download/).

This repository contains project information, usage guides, compatibility notes, and user support. It does not distribute app source code, APK/AAB packages, or game files. The initial test roster contains 28 entries (17 KTF and 11 LGT), all awaiting final verification. Inclusion in the roster is not a compatibility guarantee.

Questions and reports in Korean or English are welcome in [Issues](https://github.com/hun99999/wipi-x-releases/issues/new/choose).
